# Git Instructions

- **Branch:** work directly on `main` only. Do not create feature branches.
- **Integration branch:** `main`.
- **Push:** pre-authorized — push to `main` after each commit (`git push origin main`).
- **Pull requests:** none.
- **Parallel work:** not allowed — run features one by one (`maxParallelFeatures: 1`).
- Never force-push, never skip hooks.
